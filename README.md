# AI-Based Resume Analysis and Placement Prediction System

## Project Overview

The AI-Based Resume Analysis and Placement Prediction System is a smart web application developed to help students improve their resumes and understand their placement readiness.

The system analyzes uploaded resumes using Artificial Intelligence and compares them with job requirements to provide ATS (Applicant Tracking System) scores, skill analysis, resume feedback, and placement prediction.

This project helps students identify missing skills, improve resume quality, and increase their chances of getting shortlisted during placements.

# Working of Project

1. User uploads resume in PDF format.
2. System extracts text from the resume.
3. AI analyzes skills, keywords, and resume structure.
4. ATS score is generated.
5. Placement prediction is calculated.
6. Suggestions are provided to improve the resume.
